# 100 Reasons Why I Love You ❤️

A mobile-friendly interactive page for Elina with 100 clickable hearts and an embedded photo.

## Add to your GitHub/Vercel website

1. Open your `josh1128/elina` repository.
2. Place this entire `100-reasons` folder at the repository root (alongside your existing `index.html`).
3. Commit the files to `main`.
4. After Vercel deploys, visit `https://elina-mocha.vercel.app/100-reasons/`.
5. Send that URL via iMessage.

**Note:** The image is embedded in `index.html`, so no separate photo upload is needed. You can also open `index.html` locally to preview.

If a `100-reasons/index.html` already exists on GitHub, replace it with this version rather than creating a duplicate.
